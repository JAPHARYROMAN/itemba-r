# Database

Home of the Prisma schema and seeds for ITEMBA-R.

```
database/
├── prisma/
│   ├── schema.prisma       # Canonical schema (run from backend/)
│   └── migrations/         # Generated by `prisma migrate dev`
└── seeds/
    └── seed.ts             # Baseline Group / Companies / Divisions / Roles
```

The backend's `package.json` points at this schema via `--schema=../database/prisma/schema.prisma`, so all Prisma commands are run from `backend/`.
