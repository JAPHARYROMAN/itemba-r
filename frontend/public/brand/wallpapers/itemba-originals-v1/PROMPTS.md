# ITEMBA Originals — Volume 01

Five original wallpapers generated for ITEMBA OS using the built-in image-generation tool on 25 September 2026. No reference images were supplied. The prompts requested wide desktop compositions without text, watermarks or UI. Generated source dimensions and display asset checksums are recorded in the collection manifest; display files preserve the source dimensions without enlargement.

## Package and integration

- Installed under `frontend/public/brand/wallpapers/itemba-originals-v1/`, using the existing public brand asset route.
- Five full-quality original PNGs are included in `originals/`. Native generated resolution is 1672 × 941; no enlargement is represented as extra detail or 4K output.
- Desktop WebP images retain the original dimensions at quality 94. They range from approximately 104 to 238 KB; separate 480 × 270 thumbnails keep the picker lightweight.
- `itemba-originals-v1.zip` contains the originals, display images, previews, checksummed manifest, README and prompt set.
- Find the collection in **Control centre → Open Appearance Studio → ITEMBA Originals**. Each image is a keyboard-accessible toggle with a selected indicator. **Original theme wallpaper** restores the previous built-in theme background.
- Selection uses the existing account preference revision checks. The backend permits only these five bundled identifiers without an upload ownership lookup; all private uploads retain their owner checks. Colour themes and wallpaper selection are independent.
- Background artwork retains its colours. Desktop labels and greetings use light or dark foregrounds according to each image; app surfaces and semantic colours retain their existing theme.
